### About

I'm a software developer who likes to build things that have a reason to exist.

Most of my projects start with a question, a problem I notice, or something I think could work better. I enjoy going from **“why doesn't this exist?”** to figuring out how to turn an idea into something that actually works.

I work mostly with **Java, Spring Boot, Angular, React and cloud technologies**, but I've never been particularly interested in being tied to a specific stack. For me, **the technology comes after the problem**.

I like learning by building, experimenting with ideas, and following random curiosities wherever they lead.

Outside of technology, I'm interested in **history, literature, art, music, languages and culture**. I like having different references and letting them influence the way I think and create.

This GitHub is a collection of things I'm building, studying, experimenting with, and occasionally becoming obsessed with understanding.
